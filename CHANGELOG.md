# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-03-21

### Added

- Initial PyPI release as `aaa-docware`
- CLI tool (`aaa`) with commands: `init`, `verify`, `build`, `audit`, `check`
- Pydantic-based document codecs for all simplex types (doc, spec, guidance, chart, verification, validation, DocType, assurance)
- RDF/OWL schema definition with SHACL constraints
- Foundation layer with boundary complex bootstrap documents
- Document templates for all supported types
- `aaa init` command for scaffolding new knowledge complex projects
- MkDocs documentation site with Material theme
- CI/CD workflows for testing, linting, verification, and PyPI publishing
- Apache 2.0 license
